      1. Set up a session

      How to run a good measurement
      1. Let the participant sit and rest quietly for about 3 minutes first.
      2. Seat them at arm’s length, face lit evenly (a window or lamp in front, not behind), looking at the camera, with the reference monitor where you can read it without them turning.
      3. Press Start. For the first ~10 s CARDION is collecting data; nothing is asked of you.
      4. When the screen prompts (about every 15 s from 20 s), read the reference monitor, type the number and press Enter. If you read it a few seconds earlier, pick “from N s ago”.
      5. Stay still until the timer ends; the report appears automatically.
